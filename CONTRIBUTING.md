# Contributing

1. Create a branch and add or change a plugin under `plugins/`.
2. Register it in `.claude-plugin/marketplace.json`.
3. Run `./scripts/validate.sh`.
4. Open a PR and fill in the template.
5. Maintainers publish with `scripts/release.sh` (see docs/RELEASES.md). Do not bump `version` by hand.

See [docs/PLUGIN-GUIDELINES.md](docs/PLUGIN-GUIDELINES.md) and [docs/RELEASES.md](docs/RELEASES.md).
