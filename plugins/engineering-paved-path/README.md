# engineering-paved-path

Shared engineering skills, reused by other plugins (notably `sdd-engineering`).

| Skill | Use for |
| :- | :- |
| `react-best-practices` | Modern React patterns and anti-patterns |
| `next-best-practices` | Next.js conventions, RSC boundaries, data patterns |
| `fastify-best-practices` | Fastify servers and REST APIs |
| `react-nextjs-architecture` | Where components, hooks, utils and services live |
| `onion-architecture` | Dependency direction between layers |
| `react-testing-library` | Component testing with React Testing Library and Vitest |
| `security` | OWASP Top 10:2025 review guidance |

From other plugins, call skills by namespace, e.g.
`engineering-paved-path:react-best-practices`.

## Install

```
/plugin install engineering-paved-path@dev-digest-marketplace
```
